## 1. 직무별 코딩테스트 언어 선택 가이드

### (1) C++ (하드웨어 및 실시간 제어)

- **적용 직무**: 임베디드 SW, 제어 알고리즘, ROS/ROS2 노드 개발, 실시간(Real-time) 로봇 제어
- **평가 포인트**: Standard Template Library (STL: `vector`, `queue`, `priority_queue`, `map`)의 능숙한 활용, 스마트 포인터(`std::unique_ptr`, `std::shared_ptr`)를 활용한 메모리 누수 방지 및 포인터 연산 능력

### (2) Python (AI 및 데이터 처리)

- **적용 직무**: AI 학습/컴퓨터비전, 데이터 파이프라인 구축, 서비스 앱/백엔드
- **평가 포인트**: List Comprehension 활용, `collections`(`deque`, `Counter`), `heapq` 등 내장 라이브러리를 활용한 연산 속도 최적화 및 간결한 코드 구현

## 2. 로봇/AI 직무 코딩테스트 빈출 5대 알고리즘

일반적인 IT 서비스(웹/앱) 직무와 달리, 로봇 직무는 '공간'과 '센서 데이터'를 다루는 알고리즘의 출제 빈도가 매우 높습니다.

1. **BFS / DFS (그래프 & 격자 탐색)**
   - 2D/3D 그리드 맵(Grid Map) 상에서 로봇의 이동 가능 경로 탐색 및 장애물 충돌 검사

2. **최단 경로 알고리즘 (Dijkstra / A*)**
   - 로봇의 전역 경로 계획(Global Path Planning) 시 최단 거리 도출 및 휴리스틱(Heuristic) 기반 경로 탐색

3. **우선순위 큐 (Priority Queue / Heap)**
   - 대용량 센서 데이터 패킷의 실시간 정렬 및 이벤트 기반 큐(Queue) 처리

4. **투 포인터 & 슬라이딩 윈도우 (Sliding Window)**
   - 시계열(Time-series) 센서 스트리밍 데이터의 이동 평균(Moving Average) 계산 및 실시간 노이즈 필터링

5. **행렬 연산 및 기하학 (Math/Geometry)**
   - 2D/3D 좌표 변환(Kinematics), 회전 행렬(Rotation Matrix) 및 쿼터니언(Quaternion) 관련 기하학적 계산

## 3. 실전 통과를 위한 3대 원칙

### (1) 시간 복잡도(Big-O) 역산 설계

코드를 작성하기 전, 입력 데이터 크기 $N$을 확인하고 목표 시간 복잡도를 먼저 설정할 것.

- $N \le 100$: $O(N^3)$ (다중 루프 허용)
- $N \le 1,000$: $O(N^2)$ (이중 루프 허용)
- $N \le 100,000$: $O(N \log N)$ (정렬, 이진탐색, 우선순위 큐 필수)
- $N \le 1,000,000$: $O(N)$ 또는 $O(\log N)$ (단일 루프 또는 해시/투포인터 필수)

### (2) 가독성이 높은 코드 작성

현업 로봇 엔지니어들은 코드 가독성과 유지보수성을 중시함. 변수명을 `a`, `b`, `ans` 대신 `robot_vx`, `target_pose`, `min_distance`처럼 의미 파악이 가능하도록 작명할 것. 핵심 로직에 간결한 주석을 첨부하면 가산점을 받습니다.

### (3) 예외 조건(Edge/Corner Cases) 자체 검증

채점 시스템의 숨겨진 테스트 케이스(Hidden Test Case)에서 탈락하는 경우가 많습니다. 코드 제출 전 아래 예외 조건을 확인할 것.

- 맵 배열 범위 초과 (Out of Bounds)
- 빈 배열 입력 처리
- 음수 좌표 진입 시 예외 처리
- 분모가 0이 되는 경우 (Divide by Zero)

## 4. 추천 연습 플랫폼 및 직무 맞춤형 활용 팁

### (1) 백준 (Baekjoon Online Judge) : 시뮬레이션 및 구현 능력 강화

- **특징**: 국내 최대 알고리즘 문제 은행으로, 다양한 난이도의 문제를 제공함.
- **로봇/AI 맞춤 팁**: **'삼성 SW 역량 테스트 기출 문제'** 태그를 우선적으로 풀이하는 것을 권장함. 격자 맵 내에서의 조건 이동, 상태 변화, 2D 배열 회전 등을 다루는 문제가 많아 로봇 제어 및 자율주행 시뮬레이션 직무 코딩테스트와 결이 유사함.

### (2) 프로그래머스 (Programmers) : 대기업 실전 환경 적응

- **특징**: 국내 주요 기업들이 실제 코딩테스트 플랫폼으로 채택하고 있는 환경임.
- **로봇/AI 맞춤 팁**: IDE가 없는 웹 에디터 환경과 `solution` 함수 반환 방식에 익숙해져야 합니다. Level 2~3 수준의 카카오 기출문제(문자열 파싱, 해시, 큐 처리)를 통해 데이터 파이프라인 직무에 대비할 것.

### (3) 릿코드 (LeetCode) : 글로벌 스탠다드 및 최적화 훈련

- **특징**: 글로벌 IT 기업들이 주로 참고하는 플랫폼으로, 시간 및 공간 복잡도 비교에 용이함.
- **로봇/AI 맞춤 팁**: **Math(수학)** 및 **Geometry(기하학)** 태그 문제가 잘 구축되어 있습니다. 훌륭한 해설(Discuss 섹션)을 참고하여 C++ STL과 Python 내장 함수 활용법을 익히기 적합함.
