## 2. 로봇/AI 직무 코딩테스트 빈출 5대 알고리즘

공간 좌표와 센서 스트림 데이터를 처리하는 알고리즘 중심 출제.

1. **BFS / DFS (그래프 및 격자 탐색)**
* 2D/3D 그리드 맵(Grid Map) 상의 로봇 이동 가능 경로 탐색 및 충돌 검사.


2. **최단 경로 알고리즘 (Dijkstra / A*)**
* 자율주행 전역 경로 계획(Global Path Planning) 시 최단 거리 도출 및 휴리스틱(Heuristic) 기반 경로 탐색.


3. **우선순위 큐 (Priority Queue / Heap)**
* 대용량 센서 데이터 패킷의 시계열 정렬 및 이벤트 기반 제어 큐 처리.


4. **투 포인터 & 슬라이딩 윈도우 (Sliding Window)**
* 실시간 센서 스트리밍 데이터의 이동 평균(Moving Average) 계산 및 실시간 노이즈 필터링.


5. **행렬 연산 및 기하학 (Math / Geometry)**
* 좌표 변환(Kinematics), 회전 행렬(Rotation Matrix) 및 쿼터니언(Quaternion) 연산.

## 3. 실전 통과를 위한 3대 원칙

### (1) 시간 복잡도(Big-O) 역산 설계

코드 작성 전 입력 크기 $N$에 따른 목표 시간 복잡도 설정 필수.

* $N \le 100$: $O(N^3)$ (3중 루프 가능)
* $N \le 1,000$: $O(N^2)$ (2중 루프 가능)
* $N \le 100,000$: $O(N \log N)$ (정렬, 이진 탐색, 힙 필수)
* $N \le 1,000,000$: $O(N)$ 또는 $O(\log N)$ (단일 루프, 해시, 투 포인터 필수)

### (2) 코드 가독성 확보

실무 엔지니어의 코드 리뷰 기준 충족 필요. 변수명을 `a`, `b`, `ans` 등으로 쓰지 않고 `robot_vx`, `target_pose`, `min_dist`처럼 역할을 명시하여 작명할 것.

### (3) 예외 상황(Edge Case) 사전 검증

숨겨진 테스트 케이스(Hidden Test Case) 대응을 위해 제출 전 아래 항목 확인 필수.

* 배열 인덱스 초과 (Out of Bounds)
* 빈 배열 또는 단일 원소 입력 처리
* 음수 좌표 진입 및 제자리 상태 처리
* 0으로 나누는 연산 (Divide by Zero)
