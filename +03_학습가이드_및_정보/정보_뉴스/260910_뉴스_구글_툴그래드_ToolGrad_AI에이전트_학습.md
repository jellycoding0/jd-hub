# [AI 기술] AI타임스 | 구글 연구진, 소규모 데이터로 AI 에이전트 도구 활용력 극대화하는 '툴그래드(ToolGrad)' 공개

> **[기술 동향 | 발행일자: 2026년 09월 10일 | 출처: [AI타임스](https://www.aitimes.com)]** AI타임스 보도에 따르면 구글 연구팀이 검증된 도구 실행 경로를 먼저 생성한 후 사용자 질의를 후생성하는 '답변 우선' AI 학습 데이터 생성 프레임워크 '툴그래드(ToolGrad)'를 공개했음.

---

## 1. 주요 소식 개요
- 구글은 기존 '질의 우선' 방식의 깊이 우선 탐색(DFS)으로 인한 데이터 생성 실패와 연산 자원 낭비를 극복하기 위해 툴그래드 시스템을 제시함.
- 검증된 도구 호출 경로를 바탕으로 지시문을 역생성하여 학습 데이터 생성 성공률을 기존 63.8%에서 99.8%로 향상시킴.
- 단 500개의 정제된 툴그래드 데이터셋만으로 파인튜닝된 젬마-3(Gemma-3 12B) 모델이 버클리 함수 호출 리더보드(BFCL)에서 83.1점을 기록함.

---

## 2. 핵심 기술 스택 및 특징
- **텍스처 그래디언트 (Textual Gradient)**: API 제안자, 실행기, 선택자, LLM 업데이트 모듈 간 피드백 루프 적용.
- **One-shot 일괄 도구 호출**: ReAct 방식의 반복 탐색 지연시간을 줄이고 전체 도구 호출 경로를 한 번에 연산.

---

## 3. 로봇 취업 준비생을 위한 시사점
- **로봇 파운데이션 모델 도구 활용 능력**: VLA / LLM 에이전트가 로봇 제어 API, 이동 서비스, 센서 인터페이스를 빠르고 정확하게 호출하는 경량화 파인튜닝 원리를 이해할 수 있음.
