# 직무별 전공강의 수강 가이드

> 관심 직무에 필요한 과목을 고르고, 배운 내용을 작은 결과물로 연결하기 위한 가이드임. 모든 과목을 한 번에 수강할 필요는 없음.

**읽는 법**: 관심 직무의 수강 과목에서 부족한 기초를 먼저 확인하고, 선택 심화는 목표 채용공고에 맞춰 추가함. 학교마다 과목명과 범위가 다르므로 강의계획서와 선수과목을 함께 확인함. 도구 사용법은 관련 수업이나 개인 실습으로 보완함.

---

## 1. 직무별 수강 과목과 활용 예시

### 하드웨어

#### 1. 기구설계

* **수강 과목**: 정역학·재료역학을 기초로 동역학·기구학·기계요소설계를 학습함. 기계제도·CAD 실습을 병행함.
* **선택 심화**: 제조공정, 공차·측정, 재료 선정, 구조 해석을 보완함. 가공·조립 조건을 고려하는 연습이 필요함.
* **업무 연결**: 로봇 링크·관절·프레임에 작용하는 힘을 파악하고, 강도·무게·조립성을 고려해 형상과 부품을 결정하는 데 활용함.
* **실습 예시**: 브래킷이나 간단한 관절 구조를 설계하고, 하중 조건·재료 선정 이유·주요 치수와 공차를 도면에 정리함.

#### 2. 하드웨어 검증·해석

* **수강 과목**: 재료역학·동역학·공학통계를 바탕으로 진동공학·계측·신뢰성공학을 학습함.
* **선택 심화**: 해석 업무는 유한요소법·열역학·열전달, 시험 업무는 실험계획법·수명 분석을 중심으로 보완함.
* **업무 연결**: 부품의 변형·진동·발열을 예측하고, 시험으로 성능과 내구성을 확인하는 데 활용함. 해석의 경계조건과 시험의 측정 조건을 설명할 수 있어야 함.
* **실습 예시**: 조건을 바꾼 해석 결과를 비교하거나 반복 측정한 값의 변동을 분석함. 가정·오차 요인·추가로 확인할 사항을 보고서에 남김.

#### 3. 회로설계

* **수강 과목**: 회로이론을 기초로 전자회로·디지털 논리·신호 및 시스템을 학습하고, 회로실험으로 동작을 확인함.
* **선택 심화**: 전자기학, 전력전자·전기기기, PCB 설계, 전자파 간섭·적합성(EMI/EMC)을 담당 회로에 맞춰 보완함.
* **업무 연결**: 센서 신호를 읽는 회로, 전원부, 모터 구동부 등을 설계하고 전압·전류·잡음 문제를 분석하는 데 활용함.
* **실습 예시**: 센서 인터페이스 회로를 구성하고, 부품 선정 근거와 예상 파형을 정리함. 시뮬레이션 또는 측정값을 예상 결과와 비교함.

### 소프트웨어

#### 4. 임베디드

* **수강 과목**: C·디지털 논리·컴퓨터 구조를 기초로 마이크로프로세서·임베디드 시스템·운영체제를 학습함.
* **선택 심화**: MCU·RTOS 또는 Linux·드라이버 업무로 나눠 준비함. 모터 제어를 담당한다면 전기기기·제어 지식을 추가함.
* **업무 연결**: 센서·모터와 소프트웨어를 연결하고, 제한된 메모리와 정해진 실행 주기 안에서 장치가 동작하도록 구현하는 데 활용함.
* **실습 예시**: 센서 값을 주기적으로 수집·전송하고, 실행 시간과 통신 오류를 기록함. 연결 끊김이나 잘못된 입력을 처리하는 과정도 남김.

#### 5. 제어

* **수강 과목**: 미적분·선형대수·미분방정식을 기초로 동역학·신호 및 시스템·자동제어·로봇공학을 학습함.
* **선택 심화**: 디지털·최적·비선형 제어를 보완함. 로봇의 접촉 작업을 다룬다면 힘·임피던스 제어 등을 추가함.
* **업무 연결**: 로봇의 움직임을 모델로 표현하고, 목표 위치·속도를 따라가도록 제어기를 설계하는 데 활용함. 안정성과 응답 속도·오차 사이의 관계를 이해하는 것이 핵심임.
* **실습 예시**: 간단한 모터나 관절 모델에 제어기를 적용함. 같은 목표와 외란 조건에서 설정값에 따른 응답·오차를 그래프로 비교함.

#### 6. 자율주행

* **수강 과목**: 선형대수·확률통계·자료구조/알고리즘을 기초로 상태추정·컴퓨터 비전·로봇공학을 학습함.
* **선택 심화**: 위치추정·지도 작성(SLAM) 또는 경로계획·주행제어로 나눠 준비함. 관련 계산을 이해하기 위해 수치최적화를 보완함.
* **업무 연결**: 센서로 로봇의 위치와 주변 환경을 파악하고, 이동 경로를 정하는 데 활용함. 지도 작성과 주행 경로 평가에 쓰는 비용 지도(Costmap)는 구분해 이해함.
* **실습 예시**: 공개 로그로 위치추정 오차를 분석하거나, 같은 지도·출발점·목표점에서 경로계획 결과와 계산 시간을 비교함.

#### 7. AI·로봇 학습

* **수강 과목**: 미적분·선형대수·확률통계·Python을 기초로 머신러닝·딥러닝·최적화를 학습함.
* **선택 심화**: 인식 업무는 컴퓨터 비전, 행동 학습은 모방학습·강화학습과 로봇 기구학·제어를 보완함.
* **업무 연결**: 데이터로 물체를 인식하거나 로봇의 행동을 학습하는 데 활용함. 시뮬레이션에서 학습한 모델을 실제 환경에 적용·검증하는 Sim-to-Real은 별도의 검증 과제임.
* **실습 예시**: 학습·검증·평가 데이터를 구분하고, 기준 모델과 성능을 비교함. 잘된 사례뿐 아니라 실패 조건과 개선 방향도 정리함.

#### 8. 로봇 SW·DevOps

* **수강 과목**: 프로그래밍·자료구조를 기초로 운영체제·네트워크·소프트웨어 공학·테스트를 학습함.
* **선택 심화**: 로봇 SW는 ROS 2·동시성·통신, DevOps는 분산 시스템·DB·배포 자동화·모니터링을 중심으로 보완함.
* **업무 연결**: 여러 소프트웨어 구성요소를 연결하고, 변경 사항을 검증·배포하며 장애 원인을 추적하는 데 활용함. 개발과 운영의 비중은 채용공고마다 다름.
* **실습 예시**: 노드 간 통신과 오류 처리 테스트를 작성하거나, 빌드·테스트를 자동 실행하는 과정을 구성함. 다른 사람이 재현할 수 있도록 실행 방법을 남김.

### 생산·품질·솔루션

#### 9. 생산기술·품질

* **수강 과목**: 공학통계·도면/측정을 기초로 생산기술은 제조공정·생산관리, 품질은 품질공학·실험계획법을 학습함.
* **선택 심화**: 생산기술은 자동화 설비·공정 설계, 품질은 측정시스템 분석·신뢰성을 보완함.
* **업무 연결**: 생산기술은 안정적인 조립·검사 공정을 만들고, 품질은 측정값과 불량 원인을 분석해 제품의 일관성을 높이는 데 활용함.
* **실습 예시**: 조립 순서와 검사 지점을 정리한 공정안을 만들거나, 반복 측정값의 변동을 분석함. 개선 전후를 비교할 기준도 함께 설정함.

#### 10. 기술영업·솔루션

* **수강 과목**: 로봇공학개론으로 시스템을 이해하고, 요구사항 분석·프로젝트 관리·기술경영을 학습함. 사양서에서 성능과 제약 조건을 읽는 연습을 병행함.
* **선택 심화**: 시스템 통합, 원가·사업성 검토, 설치·시운전을 담당 업무에 맞춰 보완함.
* **업무 연결**: 고객의 작업을 로봇 요구사항으로 바꾸고, 적용 가능성·비용·검증 방법을 설명하는 데 활용함. 제품 지식과 현장 조건을 함께 이해해야 함.
* **실습 예시**: 가상의 고객 작업을 정하고, 요구사항·후보 제품 비교·검증 기준을 제안서로 작성함. 아직 확인되지 않은 조건은 가정으로 표시함.

## 2. 공통으로 챙길 기본기

* **시스템 이해**: 기구·회로·센서·제어·SW가 어떻게 연결되는지 파악함. 자기 직무의 변경이 다른 부분에 미치는 영향을 설명하는 데 도움이 됨.
* **수학과 도구**: 알고리즘은 수학·수치 계산, SW는 프로그래밍·테스트, HW는 역학·회로·도면, 품질은 통계·계측의 깊이를 우선 확보함. 언어와 도구는 실제 수행할 작업에 맞춰 선택함.
* **조건과 근거**: 단위·좌표계·측정 조건을 확인하고, 요구사항과 판단 근거를 문서로 남기는 습관이 필요함. 예를 들어 실시간 성능은 C/C++ 사용 여부만으로 판단하지 않고 실행 주기와 지연을 측정해 확인함.

## 3. 수업을 결과물로 연결하는 방법

1. **질문 하나에서 시작함**: 관심 직무를 정하고 수강한 개념으로 확인할 질문을 하나 고름. 예를 들어 제어는 설정값에 따른 오차 변화, 기구설계는 두께에 따른 변형량 차이를 확인함.
2. **가능한 환경에서 실습함**: 실물 장비가 없으면 공개 데이터·설계 검토·시뮬레이션으로 시작함. 시뮬레이터는 과제에 맞는 하나를 골라 사용하며, 여러 도구를 모두 익힐 필요는 없음.
3. **결과와 한계를 남김**: 본인 역할 → 조건·가정 → 코드/도면/시험 → 결과 → 한계 순으로 정리함. 핵심은 한 장에 요약하고 상세 자료를 덧붙임. 시뮬레이션과 실물 검증 결과는 구분함.

캡스톤·연구·대회는 이런 경험을 쌓는 기회임. 활동의 규모나 수상 여부보다 본인이 무엇을 판단하고 검증했는지 설명할 수 있는지가 중요함.
