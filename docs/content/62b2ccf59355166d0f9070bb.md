# 로보틱스 직무 모의 코딩테스트

자체 제작 연습 문제이며 실제 기업 기출이 아님. 모든 문제는 함수 solve의 인자와 반환값을 기준으로 풀이함. 예시 JSON의 키가 함수 인자명임. 별도 표준입출력 처리는 필요하지 않음.

## C01 | 센서 범위 검사 | 기초 | 10

### 문제

정수 배열 values에서 low 이상 high 이하인 값의 개수를 반환할 것. 경계값도 정상값으로 셈.

- **제약:** 0 ≤ 길이 ≤ 100000, 각 값과 경계는 -10^9~10^9, low ≤ high임.
- **작성 방식:** 예시 입력의 키를 인자로 받는 `solve` 함수를 작성함. 표준입출력 처리 없이 반환값으로 답함.

### 입출력 예시

입력 인자:
```json
{"values": [2, 5, 9, 5], "low": 3, "high": 5}
```
반환값:
```json
2
```

### 해설

조건을 만족하는 원소를 한 번씩 셈. 빈 배열의 결과는 0임.

- **복잡도:** O(n) 시간, O(1) 추가 공간
- **자기 점검:** 예시 외에 최소 크기, 경계값, 실패 조건도 실행해볼 것.

### Python

```python
def solve(values, low, high):
    return sum(low <= x <= high for x in values)
```

### C++17

아래 함수 앞에 필요한 표준 헤더와 `using namespace std;`를 추가할 것.

```cpp
int solve(const vector<int>& values, int low, int high) {
    int count = 0;
    for (int x : values) if (low <= x && x <= high) ++count;
    return count;
}
```

### 문제

0과 1로 구성된 logs에서 1이 연속으로 나오는 최대 길이를 반환할 것. 1은 정상, 0은 실패임.

- **제약:** 0 ≤ 길이 ≤ 100000임.
- **작성 방식:** 예시 입력의 키를 인자로 받는 `solve` 함수를 작성함. 표준입출력 처리 없이 반환값으로 답함.

### 입출력 예시

입력 인자:
```json
{"logs": [1, 1, 0, 1, 1, 1, 0]}
```
반환값:
```json
3
```

### 해설

현재 연속 길이를 0에서 끊고 최댓값을 갱신함. 모두 0이거나 빈 배열이면 0임.

- **복잡도:** O(n) 시간, O(1) 추가 공간
- **자기 점검:** 예시 외에 최소 크기, 경계값, 실패 조건도 실행해볼 것.

### Python

```python
def solve(logs):
    best = current = 0
    for x in logs:
        current = current + 1 if x == 1 else 0
        best = max(best, current)
    return best
```

```cpp
    int best = 0, current = 0;

    return best;
}
```

## C03 | 반복 명령 압축 | 기초 | 15

### 문제

F, L, R로 이루어진 commands에서 연속한 같은 문자를 문자와 횟수로 압축해 반환할 것. 횟수 1도 생략하지 않음.

- **제약:** 0 ≤ 문자열 길이 ≤ 100000임.
- **작성 방식:** 예시 입력의 키를 인자로 받는 `solve` 함수를 작성함. 표준입출력 처리 없이 반환값으로 답함.

### 입출력 예시

입력 인자:
```json
{"commands": "FFFLRR"}
```
반환값:
```json
"F3L1R2"
```

### 해설

연속 구간이 끝날 때 문자와 길이를 결과에 넣음. 마지막 구간도 처리해야 하며 빈 문자열은 빈 문자열을 반환함.

- **복잡도:** O(n) 시간, O(n) 결과 공간
- **자기 점검:** 예시 외에 최소 크기, 경계값, 실패 조건도 실행해볼 것.

### Python

```python
def solve(commands):
    result = []
    i = 0
    while i < len(commands):
        j = i + 1
        while j < len(commands) and commands[j] == commands[i]:
            j += 1
        result.append(commands[i] + str(j - i))
        i = j
    return "".join(result)
```

### C++17

아래 함수 앞에 필요한 표준 헤더와 `using namespace std;`를 추가할 것.

```cpp
string solve(const string& commands) {
    string result;
    for (size_t i = 0; i < commands.size();) {
        size_t j = i + 1;
        while (j < commands.size() && commands[j] == commands[i]) ++j;
        result += commands[i] + to_string(j - i);
        i = j;
    }
    return result;
}
```

## C04 | 이동 명령의 최종 좌표 | 기초 | 10

### 문제

원점 (0,0)에서 commands를 순서대로 수행한 최종 좌표 [x,y]를 반환할 것. N은 y+1, S는 y-1, E는 x+1, W는 x-1임. 장애물과 경계는 없음.

- **제약:** 문자는 N/S/E/W 중 하나이며 길이는 0~100000임.
- **작성 방식:** 예시 입력의 키를 인자로 받는 `solve` 함수를 작성함. 표준입출력 처리 없이 반환값으로 답함.

### 입출력 예시

입력 인자:
```json
{"commands": "NNEESW"}
```
반환값:
```json
[1, 1]
```

### 해설

각 문자의 변위를 누적함. 좌표축과 명령의 의미를 바꾸지 않도록 주의할 것. 빈 문자열의 결과는 [0,0]임.

- **복잡도:** O(n) 시간, O(1) 추가 공간
- **자기 점검:** 예시 외에 최소 크기, 경계값, 실패 조건도 실행해볼 것.

### Python

```python
def solve(commands):
    x = y = 0
    delta = {"N": (0, 1), "S": (0, -1), "E": (1, 0), "W": (-1, 0)}
    for c in commands:
        dx, dy = delta[c]
        x += dx
        y += dy
    return [x, y]
```

### C++17

아래 함수 앞에 필요한 표준 헤더와 `using namespace std;`를 추가할 것.

```cpp
vector<int> solve(const string& commands) {
    int x = 0, y = 0;
    for (char c : commands) {
        if (c == 'N') ++y;
        else if (c == 'S') --y;
        else if (c == 'E') ++x;
        else --x;
    }
    return {x, y};
}
```

## C05 | 최대 부하 구간 | 응용 | 20

### 문제

values의 연속한 k개 원소 합 중 최댓값을 반환할 것. 부하는 음수일 수도 있으며 평균이 아닌 합을 반환함.

- **제약:** 1 ≤ k ≤ n ≤ 100000, 각 값은 -10^9~10^9임. C++에서는 64비트 합이 필요함.
- **작성 방식:** 예시 입력의 키를 인자로 받는 `solve` 함수를 작성함. 표준입출력 처리 없이 반환값으로 답함.

### 입출력 예시

입력 인자:
```json
{"values": [4, -2, 5, 1, -3], "k": 3}
```
반환값:
```json
7
```

### 해설

첫 구간 합을 계산한 뒤 새 원소를 더하고 빠지는 원소를 뺌. 최댓값을 0으로 초기화하면 모두 음수인 경우 틀림.

- **복잡도:** O(n) 시간, O(1) 추가 공간
- **자기 점검:** 예시 외에 최소 크기, 경계값, 실패 조건도 실행해볼 것.

### Python

```python
def solve(values, k):
    total = sum(values[i] for i in range(k))
    best = total
    for i in range(k, len(values)):
        total += values[i] - values[i-k]
        best = max(best, total)
    return best
```

### C++17

아래 함수 앞에 필요한 표준 헤더와 `using namespace std;`를 추가할 것.

```cpp
long long solve(const vector<int>& values, int k) {
    long long total = 0;
    for (int i = 0; i < k; ++i) total += values[i];
    long long best = total;
    for (int i = k; i < (int)values.size(); ++i) {
        total += (long long)values[i] - values[i-k];
        best = max(best, total);
    }
    return best;
}
```

## C06 | 중복 작업 ID 탐지 | 기초 | 15

### 문제

ids를 왼쪽부터 읽을 때 이미 나온 ID를 처음 다시 만나는 위치를 반환할 것. 위치는 0부터 시작하며 중복이 없으면 -1임.

- **제약:** 0 ≤ 길이 ≤ 100000, ID는 0~10^9인 정수임.
- **작성 방식:** 예시 입력의 키를 인자로 받는 `solve` 함수를 작성함. 표준입출력 처리 없이 반환값으로 답함.

### 입출력 예시

입력 인자:
```json
{"ids": [7, 2, 9, 2, 7]}
```
반환값:
```json
3
```

### 해설

이미 확인한 ID를 집합에 저장함. 가장 작은 ID나 처음 등장한 위치가 아니라 두 번째로 나타난 시점 중 가장 이른 위치를 반환함.

- **복잡도:** 평균 O(n) 시간, O(n) 추가 공간. C++ 해시 충돌 시 최악 시간은 늘어날 수 있음
- **자기 점검:** 예시 외에 최소 크기, 경계값, 실패 조건도 실행해볼 것.

### Python

```python
def solve(ids):
    seen = set()
    for i, value in enumerate(ids):
        if value in seen:
            return i
        seen.add(value)
    return -1
```

### C++17

아래 함수 앞에 필요한 표준 헤더와 `using namespace std;`를 추가할 것.

```cpp
int solve(const vector<int>& ids) {
    unordered_set<int> seen;
    for (int i = 0; i < (int)ids.size(); ++i) {
        if (!seen.insert(ids[i]).second) return i;
    }
    return -1;
}
```

초기 배터리 battery로 costs의 작업을 순서대로 수행함. 작업 후 배터리가 reserve 이상이어야 하며 수행 불가능한 작업을 만나면 즉시 중단함. 건너뛰거나 재정렬하지 않고 수행한 작업 수를 반환할 것.



각 작업 전 남은 배터리에서 비용을 뺐을 때 예비량을 지키는지 확인함. 정확히 reserve가 남는 경우와 비용 0도 허용함.

```python
def solve(battery, reserve, costs):

    return count
```

## C08 | 설비 가동 시간 합치기 | 응용 | 25

### 문제

intervals의 [시작,종료) 구간을 합쳤을 때 전체 가동 시간의 길이를 반환할 것. 겹친 시간은 한 번만 셈. 예를 들어 [1,3)은 길이 2임.

- **제약:** 0 ≤ 구간 수 ≤ 100000, 0 ≤ 시작 < 종료 ≤ 10^9임. 입력은 정렬되어 있지 않을 수 있음.
- **작성 방식:** 예시 입력의 키를 인자로 받는 `solve` 함수를 작성함. 표준입출력 처리 없이 반환값으로 답함.

### 입출력 예시

입력 인자:
```json
{"intervals": [[5, 7], [1, 4], [3, 6], [9, 10]]}
```
반환값:
```json
7
```

### 해설

시작 시간순으로 정렬하고 현재 구간과 겹치거나 맞닿으면 종료를 늘림. 분리된 구간을 만나면 길이를 누적함. 빈 입력은 0임.

- **복잡도:** O(n log n) 시간, 아래 구현은 복사·정렬에 O(n) 공간 사용
- **자기 점검:** 예시 외에 최소 크기, 경계값, 실패 조건도 실행해볼 것.

### Python

```python
def solve(intervals):
    if not intervals:
        return 0
    ordered = sorted(intervals)
    left, right = ordered[0]
    total = 0
    for start, end in ordered[1:]:
        if start <= right:
            right = max(right, end)
        else:
            total += right - left
            left, right = start, end
    return total + right - left
```

### C++17

아래 함수 앞에 필요한 표준 헤더와 `using namespace std;`를 추가할 것.

```cpp
long long solve(vector<vector<int>> intervals) {
    if (intervals.empty()) return 0;
    sort(intervals.begin(), intervals.end());
    int left = intervals[0][0], right = intervals[0][1];
    long long total = 0;
    for (int i = 1; i < (int)intervals.size(); ++i) {
        if (intervals[i][0] <= right) right = max(right, intervals[i][1]);
        else {
            total += right - left;
            left = intervals[i][0]; right = intervals[i][1];
        }
    }
    return total + right - left;
}
```

## C09 | 격자 지도 최단 이동 | 응용 | 30

### 문제

grid의 좌상단에서 우하단까지 상하좌우로 이동할 때 최소 이동 횟수를 반환할 것. 0은 통로, 1은 장애물임. 시작 또는 도착이 장애물이거나 도달 불가능하면 -1임. 같은 칸에서 출발·도착하면 이동 0회임.

- **제약:** 1 ≤ 행·열 ≤ 100, 모든 행의 길이는 같음.
- **작성 방식:** 예시 입력의 키를 인자로 받는 `solve` 함수를 작성함. 표준입출력 처리 없이 반환값으로 답함.

### 입출력 예시

입력 인자:
```json
{"grid": [[0, 1, 0], [0, 0, 0], [1, 1, 0]]}
```
반환값:
```json
4
```

### 해설

이동 비용이 모두 1이므로 BFS를 사용함. 큐에 넣을 때 방문 거리를 기록해 중복 삽입을 막음. 1×1 지도와 막힌 시작점을 확인할 것.

- **복잡도:** O(행×열) 시간 및 추가 공간
- **자기 점검:** 예시 외에 최소 크기, 경계값, 실패 조건도 실행해볼 것.

### Python

```python
from collections import deque

def solve(grid):
    rows, cols = len(grid), len(grid[0])
    if grid[0][0] or grid[-1][-1]:
        return -1
    dist = [[-1] * cols for _ in range(rows)]
    dist[0][0] = 0
    queue = deque([(0, 0)])
    while queue:
        r, c = queue.popleft()
        if (r, c) == (rows-1, cols-1):
            return dist[r][c]
        for dr, dc in [(1,0),(-1,0),(0,1),(0,-1)]:
            nr, nc = r+dr, c+dc
            if 0 <= nr < rows and 0 <= nc < cols and grid[nr][nc] == 0 and dist[nr][nc] == -1:
                dist[nr][nc] = dist[r][c] + 1
                queue.append((nr, nc))
    return -1
```

### C++17

아래 함수 앞에 필요한 표준 헤더와 `using namespace std;`를 추가할 것.

```cpp
int solve(const vector<vector<int>>& grid) {
    int rows = grid.size(), cols = grid[0].size();
    if (grid[0][0] || grid[rows-1][cols-1]) return -1;
    vector<vector<int>> dist(rows, vector<int>(cols, -1));
    queue<pair<int,int>> q; q.push({0,0}); dist[0][0] = 0;
    int dr[] = {1,-1,0,0}, dc[] = {0,0,1,-1};
    while (!q.empty()) {
        auto [r,c] = q.front(); q.pop();
        if (r == rows-1 && c == cols-1) return dist[r][c];
        for (int i = 0; i < 4; ++i) {
            int nr = r+dr[i], nc = c+dc[i];
            if (nr>=0 && nr<rows && nc>=0 && nc<cols && !grid[nr][nc] && dist[nr][nc]==-1) {
                dist[nr][nc] = dist[r][c]+1; q.push({nr,nc});
            }
        }
    }
    return -1;
}
```

## C10 | 가중 경로의 최소 비용 | 응용 | 35

### 문제

n개 지점(0~n-1)과 단방향 간선 edges=[출발,도착,비용]이 주어짐. 0에서 n-1까지 최소 비용을 반환하고 도달 불가능하면 -1임. 중복 간선·자기 연결을 허용함.

- **제약:** 1 ≤ n ≤ 10000, 0 ≤ 간선 수 ≤ 100000, 비용은 0~10^6임. C++에서는 64비트 거리가 필요함.
- **작성 방식:** 예시 입력의 키를 인자로 받는 `solve` 함수를 작성함. 표준입출력 처리 없이 반환값으로 답함.

### 입출력 예시

입력 인자:
```json
{"n": 4, "edges": [[0, 1, 5], [0, 2, 1], [2, 1, 1], [1, 3, 2], [2, 3, 9]]}
```
반환값:
```json
4
```

### 해설

음수가 없는 가중치이므로 우선순위 큐를 쓰는 다익스트라로 최단 거리를 갱신함. 큐에서 꺼낸 비용이 현재 거리와 다르면 버림. 단방향 조건과 도달 불가를 확인할 것.

- **복잡도:** O((V+E) log(E+2)) 시간, O(V+E) 공간
- **자기 점검:** 예시 외에 최소 크기, 경계값, 실패 조건도 실행해볼 것.

### Python

```python
import heapq

def solve(n, edges):
    graph = [[] for _ in range(n)]
    for u, v, w in edges:
        graph[u].append((v,w))
    dist = [float("inf")] * n
    dist[0] = 0
    queue = [(0,0)]
    while queue:
        cost, u = heapq.heappop(queue)
        if cost != dist[u]:
            continue
        if u == n-1:
            return cost
        for v, w in graph[u]:
            if cost+w < dist[v]:
                dist[v] = cost+w
                heapq.heappush(queue, (cost+w,v))
    return -1
```

### C++17

아래 함수 앞에 필요한 표준 헤더와 `using namespace std;`를 추가할 것.

```cpp
long long solve(int n, const vector<vector<int>>& edges) {
    vector<vector<pair<int,int>>> graph(n);
    for (auto e : edges) graph[e[0]].push_back({e[1],e[2]});
    const long long INF = LLONG_MAX;
    vector<long long> dist(n, INF); dist[0] = 0;
    using Item = pair<long long,int>;
    priority_queue<Item, vector<Item>, greater<Item>> q; q.push({0,0});
    while (!q.empty()) {
        auto [cost,u] = q.top(); q.pop();
        if (cost != dist[u]) continue;
        if (u == n-1) return cost;
        for (auto [v,w] : graph[u]) {
            if (cost+w < dist[v]) {
                dist[v] = cost+w; q.push({dist[v],v});
            }
        }
    }
    return -1;
}
```
