## Q1. [개념/이론] CNN의 동작 원리와 Pooling의 역할에 대해 설명하면? [빈출]

* **답변 요약**: 합성곱은 국소 영역에 공유 가중치를 적용해 공간 특징을 추출함. Pooling은 특징맵을 요약·축소해 후속 연산량을 줄이고 작은 위치 변화에 대한 민감도를 낮출 수 있음.
* **주의 조건**: 일반적인 pooling 자체에는 학습 파라미터가 없으며 위치 정보도 손실될 수 있음. 모든 크기의 이동에 대한 완전한 불변성을 보장하지는 않음.

## Q2. [개념/이론] Object Detection에서 1-stage detector와 2-stage detector의 차이는 무엇인가? [빈출]

* **답변 요약**: 2-stage 방식은 후보 영역 생성 후 분류·위치 보정을 수행하고, 1-stage 방식은 별도 후보 영역 단계 없이 탐지를 수행함. 구조에 따라 처리량과 학습·추론 특성이 달라짐.
* **주의 조건**: 정확도·지연의 우열은 모델 크기·해상도·데이터·실행 장치에 따라 비교함. 탐지 FPS만으로 로봇 전체 제어의 실시간성을 판단하지 않음.

## Q3. [실무/트러블슈팅] Overfitting이 발생했을 때 이를 해결하기 위한 엔지니어링 접근법은? [빈출]

* **답변 요약**: 학습·검증 성능 차이와 데이터 분리 기준을 먼저 확인함. 같은 주행·장면의 유사 프레임이 양쪽에 섞이지 않도록 하고, 전처리 통계는 학습 데이터로만 추정함.
* **개선 방법**: 데이터 품질·증강, 정규화, 모델 복잡도, 조기 종료 등을 비교함. 독립 평가 데이터는 튜닝에 반복 사용하지 않으며, 환경별 성능과 실패 사례를 함께 확인함.
* **꼬리 질문**: 프레임 단위 무작위 분리와 주행·장소 단위 분리는 평가 결과를 어떻게 바꿀 수 있는가?
* **참고**: [scikit-learn 데이터 누수 방지](https://scikit-learn.org/1.5/common_pitfalls.html)

## Q4. [개념/이론] 활성화 함수로 Sigmoid 대신 ReLU 계열을 주로 사용하는 이유는 무엇인가? [빈출]

* **답변 요약**: Sigmoid는 입력 절댓값이 클 때 미분값이 0에 수렴하여 역전파 시 기울기 소실(Vanishing Gradient)이 발생함. ReLU는 양수 영역의 기울기가 1로 유지되어 역전파 시 기울기 소실을 억제하며, 지수 연산이 없어 연산 속도가 빠름.

---

## Q5. [개념/이론] Batch Normalization의 동작 원리와 도입 효과는? [빈출]

* **답변 요약**: 학습 중 배치 통계로 활성값을 정규화하고 학습 가능한 스케일·이동 값을 적용함. 학습을 안정화하고 수렴을 돕지만 효과는 모델·데이터·배치 크기에 따라 달라짐.
* **주의 조건**: 일반적인 설정에서는 추론 시 누적 통계를 사용함. 학습·평가 모드와 통계 설정, 작은 배치나 환경 변화의 영향을 확인함. 효과를 내부 공변량 변화 하나로만 설명하지 않음.

---

## Q6. [개념/이론] Vision Transformer(ViT)의 특징과 기존 CNN과의 차이점은? [빈출]

* **답변 요약**: CNN은 국소 연결과 가중치 공유를 활용하고, ViT는 이미지 패치를 토큰으로 만들어 attention으로 관계를 학습함. 데이터 규모·사전학습·증강과 모델 구조에 따라 성능이 달라짐.
* **주의 조건**: 대규모 사전학습은 유용한 선택이지만 모든 ViT의 필수 조건으로 단정하지 않음. 목표 해상도와 장치에서 정확도·메모리·추론 지연을 비교함.

## Q7. [실무/트러블슈팅] Sim-to-Real Transfer(시뮬레이션 정책의 실물 로봇 적용) 시 발생하는 Domain Gap 극복 방법은? [빈출]

## Q8. [개념/이론] 3D Point Cloud 데이터 처리를 위한 PointNet/PointNet++의 핵심 구조는? [빈출]

* **답변 요약**: 점군의 순서 불변성(Permutation Invariance)을 만족시키기 위해 대칭 함수인 Max Pooling을 채택함. PointNet은 전역 특징만 추출하는 한계가 있어, PointNet++는 Hierarchical Feature Learning 구조(Sampling 및 Grouping)를 도입해 국소적(Local) 기하 구조를 단계적으로 학습함.

## Q10. [시스템/응용] 엣지 보드(NVIDIA Jetson 등) 탑재를 위한 모델 경량화 기법(양자화, 가지치기, 지식 증류)의 차이는? [빈출]

**답변 요약**

* **Quantization(양자화)**: FP32 가중치/활성화를 INT8 등으로 축소하여 메모리 대역폭 절감 및 TensorRT 연산 가속.

* **Knowledge Distillation(지식 증류)**: 큰 교사 모델(Teacher)의 출력을 작은 학생 모델(Student)이 학습하도록 유도.

## Q20. [시스템/응용] Imitation Learning에서 Behavioral Cloning과 DAgger 알고리즘의 차이와 한계 극복 방식은? [빈출]

* **답변 요약**: Behavioral Cloning은 전문가의 상태·행동 쌍을 지도학습함. 학습 데이터에서 벗어난 상태를 만나면 오차가 누적될 수 있으나, 항상 복구 불가능하다는 의미는 아님.
* **DAgger**: 학습한 정책이 방문한 상태에 대한 전문가 행동을 추가 수집해 데이터셋을 누적하고 재학습함. 전문가의 라벨링 비용과 정책 실행 중 안전한 데이터 수집 조건도 검토함.
