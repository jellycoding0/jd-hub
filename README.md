## 대시보드 주요 기능 및 활용법

### 1. 실시간 통합 검색
- 메인 화면 좌측 상단의 **통합 검색창**에 회사명, 직무 타이틀, 특정 기술 스택(예: `Python`, `PyTorch`, `C++`, `ROS` 등)을 입력하면 관련 공고가 실시간으로 필터링됩니다.

### 2. 메인 탭 네비게이션
- **채용정보**: 기업별 채용공고 탐색 및 검색
- **취업준비**: 취업전략·서류·면접·인성검사·코딩테스트 가이드
- **실전연습**: 면접기출, 직무별 모의면접, 모의인성검사, 모의 코딩테스트
- **산업소식**: 로봇 산업 뉴스 아카이브
- **학습·강의**: 전공강의 수강 가이드와 실무 프로젝트 강의

### 3. 기업 및 경력 구분 필터링
- 좌측 사이드바의 **기업 필터** 및 **채용 구분(신입/경력)** 태그로 원하는 포지션들을 한눈에 비교해볼 수 있습니다.

### 4. 상세 직무 기술서(JD) 열람
- 직무 카드를 클릭하면 우측에서 상세 내용이 슬라이딩 형태로 나타나며, **해당 직무의 구체적인 개요, 주요 업무, 요구 역량**을 확인할 수 있습니다.


### 모의 코딩테스트 문항 관리
- 원문: `+03_학습가이드_및_정보/_모의코딩테스트.md`
- `## C01 | 문제 제목 | 기초 | 10` 형식으로 문항을 구분함. ID는 중복 없이 작성하고 난이도는 `기초` 또는 `응용`, 권장 시간은 1~120분으로 지정함.
- `### 문제`, JSON 입출력 예시, `### 해설`, Python 및 C++ 코드 블록을 유지함. 해설 이후 내용은 사용자가 해설을 열 때 표시됨.
- 원문 변경 후 로컬 `python -X utf8 build_dashboard.py`를 실행하면 `docs/content/*.md`와 `docs/jobs.js`의 `CODING_TEST_DATA`가 갱신됨. 빌더는 로컬 관리 파일이며 이 저장소에 포함되지 않음.
- `docs/coding-test.js`가 Markdown을 fetch하여 표시함. 풀이 초안은 현재 연습 화면의 메모리에만 유지되며 탭 이동·새로고침 시 초기화됨. 자동 실행·채점 기능은 없음.
