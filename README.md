수강생(멘티)들이 취업 준비 및 직무 분석을 효율적으로 진행할 수 있도록 돕는 **로보틱스 & AI 채용공고 & 면접 기출 아카이브 대시보드**입니다.

## 폴더 구조 안내

- **`+01_기업별`**: 279개 이상 로봇/자동화/AI 기업별 채용공고(JD) 마크다운 DB
- **`+02_직무별_면접_기출`**: 16개 핵심 기술 직무별 면접 빈출 기출 Q&A DB
- **`+03_학습가이드_및_정보`**: 전공강의 수강 가이드, 꿀팁 4종(실무/인성/인성검사/코테), 로봇 산업 뉴스, 실무 프로젝트 커리큘럼
  - **`정보_뉴스`**: `YYMM_` 접두사가 붙은 최신 로봇 산업 뉴스 기사 모음
- **`docs`**: GitHub Pages 웹앱 컴파일 및 배포 디렉토리

## 대시보드 주요 기능 및 활용법

### 1. 실시간 통합 검색
- 메인 화면 좌측 상단의 **통합 검색창**에 회사명, 직무 타이틀, 특정 기술 스택(예: `Python`, `PyTorch`, `C++`, `ROS` 등)을 입력하면 관련 공고가 실시간으로 필터링됩니다.

### 2. 메인 탭 네비게이션
- **채용공고 모음**: 전체 기업 채용공고 탐색 및 검색
- **직무별 면접기출 & 꿀팁**: 실무/인성/인성검사/코테 4대 합격 꿀팁 및 16개 핵심 직무별 면접 기출 20개 문항 DB 통합 열람
- **로봇 산업 뉴스**: 최신 로봇 산업 기사 아카이브 (테슬라, 유니트리, 보스턴다이나믹스, 현대차, 삼성, LG, 두산, 엔비디아 등)
- **로봇 실무 프로젝트/강의**: 직무별 추천 실무 프로젝트 및 커리큘럼

### 3. 기업 및 경력 구분 필터링
- 좌측 사이드바의 **기업 필터** 및 **채용 구분(신입/경력)** 태그로 원하는 포지션들을 한눈에 비교해볼 수 있습니다.

### 4. 상세 직무 기술서(JD) 열람
- 직무 카드를 클릭하면 우측에서 상세 내용이 슬라이딩 형태로 나타나며, **해당 직무의 구체적인 개요, 주요 업무, 요구 역량**을 확인할 수 있습니다.
