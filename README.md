# 🤖 ROBO-JD: 로보틱스 & AI 채용공고 아카이브

수강생(멘티)들이 취업 준비 및 직무 분석을 효율적으로 진행할 수 있도록 돕는 **로보틱스 & AI 채용공고 아카이브 대시보드**입니다.

## 🔗 웹 대시보드 바로가기
> **채용 대시보드 주소**: [https://jellycoding0.github.io/jd-hub/](https://jellycoding0.github.io/jd-hub/)
> *(클릭하면 대시보드 웹페이지로 이동합니다)*

> [!TIP]
> **대시보드 화면이 깨지거나 최신 정보가 안 뜰 때**:
> 브라우저 캐시 현상일 수 있으니 **`Ctrl` + `F5`** (Mac 사용자는 **`Cmd` + `Shift` + `R`**)를 눌러 강력 새로고침을 진행해 주세요!

---

## 💡 대시보드 주요 기능 및 활용법

### 1. 실시간 통합 검색
*   메인 화면 좌측 상단의 **통합 검색창**에 회사명, 직무 타이틀, 특정 기술 스택(예: `Python`, `PyTorch`, `C++`, `ROS` 등)을 입력하면 관련 공고가 실시간으로 필터링됩니다.

### 2. 직무 카테고리 필터
*   원하는 기술 도메인 배지(`ai`, `control`, `embedded`, `hardware`, `autonomous-driving` 등)를 클릭하여 관심 있는 직무들만 모아서 조회할 수 있습니다.
*   다중 선택이 지원되어, 복합적인 직무(예: AI와 제어를 동시에 요구하는 직무)도 손쉽게 탐색이 가능합니다.

### 3. 기업별 필터링
*   좌측 사이드바의 **기업 필터** 목록에서 원하는 회사들만 체크박스로 지정하여 포지션들을 한눈에 비교해볼 수 있습니다.

### 4. 상세 직무 기술서(JD) 열람
*   직무 카드를 클릭하면 우측에서 상세 내용이 슬라이딩 형태로 나타납니다. 해당 직무의 구체적인 **직무 개요, 주요 업무, 요구 역량**을 마크다운 스타일로 깔끔하게 확인할 수 있습니다.
