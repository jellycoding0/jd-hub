# Staff Firmware Engineer

## 공고 기준
- 회사: Agility Robotics
- 게시일: 2026-02-02
- 근무지: Hybrid - Fremont, CA
- 출처: https://www.agilityrobotics.com/about/job-post?gh_jid=5789714004

## 직무 개요
휴머노이드 로봇의 저수준 센서 네트워크, 제어, 전원 관리 시스템을 구동하는 firmware architecture를 설계하고 구현하는 직무
하드웨어와 상위 로봇 제어 알고리즘 사이의 interface를 안정적으로 연결하는 역할

## 주요 업무
- C++ 기반 robot firmware architecture 설계 및 구현
- EtherCAT, CAN 기반 firmware communication layer 개발
- Hardware abstraction layer, peripheral driver, application firmware 작성
- Logic analyzer, oscilloscope 등 계측 장비를 활용한 실시간 하드웨어 테스트/디버깅
- HW/SW 통합 문제 해결 및 interface 문서화

## 요구 역량
- Modern C++ 기반 firmware 개발 경험
- FreeRTOS 또는 유사 RTOS 경험
- EtherCAT, CAN, 센서 네트워크, 전원관리, 실시간 제어 이해
- 회로/하드웨어와 함께 디버깅할 수 있는 역량
