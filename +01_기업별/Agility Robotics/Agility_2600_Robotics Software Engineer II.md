# Robotics Software Engineer II

## 공고 기준
- 회사: Agility Robotics
- 게시일: 2026-06-09
- 근무지: Hybrid - Pittsburgh, PA or Salem, OR
- 출처: https://www.agilityrobotics.com/about/job-post?gh_jid=6008698004

## 직무 개요
휴머노이드 로봇 Digit의 production-ready skill을 개발, 테스트, 검증, 통합하는 직무
프로토타입과 실제 고객 워크플로우 사이에서 로봇 행동을 구현하고, 현장 성능을 확인하며, 실패 원인을 분석하는 역할

## 주요 업무
- 고객 업무 흐름에 들어갈 로봇 skill 및 behavior 구현
- Behavior tree, state machine, task planner 기반의 로봇 동작 시퀀스 작성
- 실제 로봇 하드웨어에서 성능 평가, 실패 분석, 테스트 플랜 수행
- Teleoperation 데이터 수집과 learned behavior 개선 지원
- AI, 제어, perception 팀과 협업하여 skill API 기반 워크플로우 통합

## 요구 역량
- 로봇 SW 개발 경험
- Python/C++ 기반 로봇 시스템 구현 역량
- 로봇 하드웨어 디버깅과 실험 설계 경험
- 상태기계, 행동트리, task planning 등 로봇 행동 설계 이해
- 실제 배치 환경에서 reliability를 높이는 문제 해결 능력
