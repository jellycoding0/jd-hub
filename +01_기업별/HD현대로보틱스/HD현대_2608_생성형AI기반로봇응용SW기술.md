# 생성형 AI기반 로봇응용 SW기술

- **소속:** 지능화소프트웨어개발팀
- **구분:** 경력
- **학력:** 학사 이상
- **근무지:** 분당 (GRC)

## 수행 업무
- 생성형 AI기반 로봇 제어 코드 생성 기술개발
  - 생성형 AI 기반 로봇 제어 알고리즘 개발
  - 코드 자동 생성 및 변환 서비스 설계 및 구현
- 생성형 AI기반 사용자 의도추론 및 시퀀스 분리 기술 개발
  - 비정형 자연어 명령에 대한 의도분석 및 단계별 하위 작업 분할 알고리즘 개발
  - 복잡한 다단계 임무를 수행하는 로봇 Agent OS 아키텍처 설계 및 개발
  - 상황 변화에 대응하는 동적 경로 및 행동 재계획 시스템 구축

## 우대 사항 / 지원 자격
- C++/Python/ROS2 프로그래밍 언어 활용능력 (필수)
- LLM(대형언어모델) 및 NLP(자연어처리) 모델 기반 로봇 응용 SW개발 프로젝트 수행 경험 (필수)
- LangChain, LlamaIndex 등을 활용한 AI Agent 설계/개발 경험 (필수)
- ROS / ROS2 환경에서의 로봇 제어 또는 어플리케이션 개발 경험 (필수)
- 생성형 AI(LLM, VLA) 기반 어플리케이션 개발 경험
- 생성형 AI 기반 로봇 제어 및 스크립트 언어 자동생성 프로젝트 경험
- 로봇 시뮬레이터(Isaac Sim, PyBullet, MuJoCo 등) 활용 능숙자
- 임베디드 타겟 대상 AI 모델 경량화 및 최적화 경험
