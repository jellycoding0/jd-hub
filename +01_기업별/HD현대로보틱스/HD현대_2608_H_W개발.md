# H/W개발

- **소속:** 제어플랫폼개발팀
- **구분:** 경력
- **학력:** 학사 이상
- **근무지:** 분당 (GRC)

## 수행 업무
- 로봇 제어기 하드웨어 설계
  - 아날로그 및 디지털 회로 설계, 제어기 구조 설계
  - 신뢰성 확보 및 규격 인증 / 안전 기능
- 협동로봇 전장 HW 설계
  - 각종 센서 인터페이스 보드 / IO, 통신 보드

## 우대 사항 / 지원 자격
- 하드웨어 설계 분야 3년 이상의 경력 (필수)
  - 회로 설계 및 시뮬레이션 툴 사용 가능자 (Orcad, Altium, Matlab 등)
  - Digital/Analog 회로 설계 가능자, 회로 시뮬레이션 가능자
- 로봇제어기 전장 보드 설계 경험자
- 협동로봇 전장 보드 설계 경험자
