# 양팔 로봇 전장시스템

- **소속:** 연구기획파트
- **구분:** 경력
- **학력:** 학사 이상
- **근무지:** 분당 (GRC)

## 수행 업무
- 양팔로봇(휴머노이드)향 전장 보드 펌웨어 개발
  - 48V/24V 전원 제어 및 모니터링 설계
  - 센서 인터페이스 설계
  - RS485/UART/SPI 통신 프로토콜 설계

## 우대 사항 / 지원 자격
- 로봇 전장 시스템 설계 경험
- ST/TI/Renesas MCU 개발 경험
- Safety function 사양 개발 경험
- EtherCAT/SPI/UART 통신 프로토콜에 대한 이해
