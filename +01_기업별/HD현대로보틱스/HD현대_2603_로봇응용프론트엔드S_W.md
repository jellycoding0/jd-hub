# 로봇 응용 프론트엔드 S/W

- **구분:** 경력
- **학력:** 학사 이상
- **근무지:** 분당 (GRC)

## 수행 업무
  - 로봇 티칭펜던트 및 웹/앱 기반 UI/UX 프론트엔드 개발
  - 3D 로봇 뷰어 및 3D 씬(Scene) 렌더링 화면 구현
  - 제어기 백엔드 REST API / WebSocket 통신 연동 인터페이스 작성

## 지원 자격
  - 학사 이상 (컴퓨터공학, SW 관련 전공)
  - React, Vue.js, Electron, TypeScript 등 프론트엔드 개발 경력 3년 이상
  - WebGL 또는 Three.js 활용 3D 그래픽스 개발 경험자

## 우대 사항
  - 산업용 웹 UI 또는 모바일 UI 앱 개발 및 상용화 경험자
  - Figma 등을 통한 UI/UX 설계 및 디자인 시스템 구축 경험자
