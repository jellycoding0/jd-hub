# SW개발 (용접솔루션)

- **소속:** 용접솔루션개발팀
- **구분:** 경력
- **학력:** 학사 이상
- **근무지:** 분당 (GRC)

## 수행 업무
- 지능형 로봇 자동화 시스템 SW 설계 및 개발
- 로봇 경로 생성 및 모션 제어 SW 개발
- 3D 비전 및 로봇 인지 시스템 개발
- 로봇 시스템 통합 및 플랫폼 개발

## 우대 사항 / 지원 자격
- 조선 자동화 시스템 개발 경험
- 산업용 로봇 API/SDK 기반 제어 SW 개발 경험
- 자율 로봇 프로그래밍 또는 Robot Path Planning 시스템 개발 경험
- ROS/ROS 2, MoveIt 등 로봇 SW Framework 활용 경험
- OpenCV, PCL, Open3D 등 Computer Vision 활용 경험
- 3D Vision, Point Cloud Processing 등 Scan-to-Path 개발 경험
- CUDA/GPU 기반 병렬처리 및 AI/Deep Learning 적용 경험
