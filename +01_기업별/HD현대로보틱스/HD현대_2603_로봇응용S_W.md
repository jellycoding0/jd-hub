# 로봇 응용 S/W

- **구분:** 경력
- **학력:** 학사 이상
- **근무지:** 분당 (GRC)

## 수행 업무
  - 로봇 애플리케이션(팔레타이징, 용접, 이재, 봉지 등) 로직 개발
  - 사용자 인터페이스(UI/UX) 연동 및 애플리케이션 API 개발
  - 고객 맞춤형 로봇 솔루션 패키지 S/W 구현

## 지원 자격
  - 학사 이상 (컴퓨터공학, 로봇공학, 소프트웨어 관련 전공)
  - C++, C#, Python 중 1개 이상 개발 경력 3년 이상
  - 로봇 응용 로직 및 공정 알고리즘 이해도 보유자

## 우대 사항
  - 산업용 로봇 애플리케이션 개발 경험자
  - Qt, WPF 등 GUI 프레임워크 개발 경험자
