# 로봇비전 알고리듬

- **소속:** 지능화소프트웨어개발팀
- **구분:** 경력
- **학력:** 학사 이상
- **근무지:** 분당 (GRC)

## 수행 업무
- 3차원 영상 처리 알고리듬 개발
  - 3차원 센서 I/F 및 점군데이터 처리 기술 개발
  - Multi-View Geometry 기반 3차원 형상 복원
  - 카메라 캘리브레이션 기술 개발
  - 3D 객체 분할/검출(Object Segmentation, Detection) 기술 개발
  - 객체 추적(Object Tracking) 기술 개발
  - 3차원 공간 인식 및 자세 추정(6D Pose Estimation) 기술 개발
  - RGB, Depth, Point Cloud 기반 비전 검사 알고리즘 개발
- 딥러닝 기반 비전 알고리듬 개발
  - Object Detection, Segmentation, Pose Estimation 모델 개발
  - 비전 기반 결함 검출 및 이상 탐지(Anomaly Detection) 모델 개발
  - 데이터셋 구축, 라벨링 및 데이터 증강 기술 개발
  - 시스템 통합(Integration) 및 실 환경 대상 검증/최적화

## 우대 사항 / 지원 자격
- 유관 경력 5년 이상(석사 2년, 박사 8년 인정) (필수)
- C++/C#/Python 프로그래밍 언어 활용 능력 (필수)
- ROS, 딥러닝 및 강화학습 개발 경험 보유 (필수)
- OpenCV, PCL, Open3D 등 활용 가능자 (필수)
- 산업용 로봇 비전 적용 상품화 개발 경험자
