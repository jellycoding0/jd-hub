# 로봇 안전기능 개발

- **소속:** 제어플랫폼개발팀
- **구분:** 경력
- **학력:** 학사 이상
- **근무지:** 분당 (GRC)

## 수행 업무
- 로봇 안전기능 알고리즘 개발
  - 기능 안전 SW 개발 및 기구학 / 동역학 기반 로봇 모니터링 개발
  - 3D 형상 충돌 알고리즘 개발
  - 로봇 안전 기능 시뮬레이션 개발 및 안전 인증
- 로봇 안전 응용기능 개발

## 우대 사항 / 지원 자격
- 이공계열 전공 (필수)
- 유관 분야 3년 이상의 경력 (필수)
  - 다관절 로봇 제어 알고리즘에 대한 이해
  - C/C++ 프로그래밍 언어 활용능력
- 다관절로봇 제어 알고리즘 개발 경험
- 로봇 안전 기능 개발 및 인증 프로세스 경험
