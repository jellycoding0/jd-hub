# 로봇 VLA / RFM 기술개발

- **소속:** 지능화소프트웨어개발팀
- **구분:** 경력
- **학력:** 학사 이상
- **근무지:** 분당 (GRC)

## 수행 업무
- 공정 도메인 특화 VLA, RFM 기술개발
  - 신규 로봇 파운데이션 모델(RFM) 및 VLA 모델 학습
  - 멀티모달 데이터(Web Data), 로봇 데이터(Sim/Real) 구축 및 데이터 증강(Data Augmentation)
  - 시뮬레이션 환경(Isaac Sim, MuJoCo 등)과 실세계 로그를 통한 Sim-to-Real 및 데이터 합성(Data Synthesis)

## 우대 사항 / 지원 자격
- 유관 경력 5년 이상(석사 2년, 박사 8년 인정) (필수)
- C++/Python/ROS2 프로그래밍 언어 활용능력 (필수)
- NVIDIA Isaac(Isaac Sim/Gym/Lab 등) 환경을 활용한 로봇 강화학습(RL) 개발 및 시뮬레이션 경험 보유 (필수)
- 멀티모달(Vision-Language) 데이터 또는 로봇 행동(Action) 데이터 기반의 VLA / RFM 데이터셋 구축 및 모델 학습 보유 (필수)
- 생성형 AI 모델 기반의 가상 데이터 합성(Synthetic Data Generation) 기술 개발 경험
- 모방학습 및 강화학습 기반의 로봇 제어 알고리즘 개발 경험
- PyTorch 기반의 대규모 분산 학습 인프라(Multi-GPU) 운영 및 최적화 경험
