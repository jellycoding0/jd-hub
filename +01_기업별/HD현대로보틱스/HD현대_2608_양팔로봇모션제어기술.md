# 양팔 로봇 모션제어기술

- **소속:** 연구기획파트
- **구분:** 경력
- **학력:** 학사 이상
- **근무지:** 분당 (GRC)

## 수행 업무
- 양팔로봇(휴머노이드) Dual Arm 제어 알고리즘 개발
  - 다자유도 로봇 매니퓰레이터 모션 제어
  - Dual-arm task 경로 생성 및 최적화
  - Xenomai RTOS 기반 Application 개발

## 우대 사항 / 지원 자격
- 로봇 시스템 HW 설계 경력자
- EtherCAT synchronous 제어 경험자
- 다관절 동역학 simulation (MATLAB, RecurDyn, RoboticsLab 등) 경력자
