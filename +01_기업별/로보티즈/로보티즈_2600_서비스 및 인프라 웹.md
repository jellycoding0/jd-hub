# 서비스 및 인프라 웹 개발자

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 웹 기반 서비스, 관리 시스템, 사내 업무 시스템을 개발하고 운영합니다.
- PHP, JavaScript 기반 기능 구현과 API 연동을 수행합니다.
- 클라우드 서버, Linux 인프라, 데이터베이스 운영 환경을 관리합니다.
- 로봇 서비스 운영에 필요한 관리자 도구와 데이터 조회 기능을 개선합니다.

## 지원자격
- PHP와 JavaScript를 활용한 웹 개발 경험이 필요합니다.
- REST API 설계, DBMS 운영, 쿼리 최적화 경험이 필요합니다.
- Linux 서버와 웹 서비스 배포 구조에 대한 이해가 필요합니다.

## 우대사항
- AWS 또는 클라우드 인프라 구축/운영 경험
- ERP, 쇼핑몰, 기업용 관리 시스템 개발 경험
- AI Agent 또는 로봇 서비스와 웹 시스템 연동 경험
