# 자율주행로봇 시스템 Backend 개발

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 자율주행 로봇 관제, 운영, 데이터 수집을 위한 백엔드 시스템을 개발합니다.
- 로봇 상태, 주행 로그, 미션, 지도, 사용자 요청을 처리하는 API를 설계합니다.
- 로봇과 서버 간 통신 안정성, 장애 대응, 데이터 저장 구조를 개선합니다.
- 운영자 도구와 서비스 플랫폼이 사용할 수 있는 서버 기능을 제공합니다.

## 지원자격
- 백엔드 서버 개발 및 API 설계 경험이 필요합니다.
- 데이터베이스, 메시징, 인증, 로그 처리 등 서비스 운영 기본기가 필요합니다.
- 로봇 또는 IoT 디바이스와 연동되는 시스템 구조에 대한 이해가 있으면 적합합니다.

## 우대사항
- 로봇 관제 시스템, fleet management, IoT backend 개발 경험
- Docker, Kubernetes, 클라우드 인프라 운영 경험
- 실시간 통신, MQTT/WebSocket/gRPC 활용 경험
