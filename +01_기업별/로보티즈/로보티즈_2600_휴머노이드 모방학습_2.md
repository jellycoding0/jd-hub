# 휴머노이드 모방학습 연구원

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 휴머노이드가 사람 동작과 작업 절차를 학습할 수 있도록 모방학습 알고리즘을 연구합니다.
- 시연 데이터 수집 방식, 데이터 품질 기준, 학습 목표를 설계합니다.
- 행동 정책 모델을 학습하고 다양한 태스크에서 일반화 성능을 평가합니다.
- 강화학습, VLA, teleoperation 시스템과 연계하여 성능을 개선합니다.

## 지원자격
- 로봇학습, 모방학습, 딥러닝 연구 경험이 필요합니다.
- Python/PyTorch 기반 실험 구현과 논문 기반 알고리즘 재현 역량이 필요합니다.
- 로봇 운동학, 제어, 센서 데이터에 대한 기본 이해가 있으면 적합합니다.

## 우대사항
- 로봇 정책 학습, diffusion policy, sequence model 경험
- 휴머노이드/매니퓰레이터 데이터 수집 및 실험 경험
- Sim-to-Real, Domain Adaptation, Dataset Curation 경험
