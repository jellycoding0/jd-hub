# 휴머노이드 Navigation 엔지니어

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 휴머노이드 로봇이 실내외 공간을 이동하기 위한 경로 계획 및 주행 판단 기능을 개발합니다.
- 보행 제어, 장애물 회피, 위치 추정, 지도 정보를 연동한 navigation stack을 구성합니다.
- 사람 환경에서 안전하게 이동하기 위한 local planning과 recovery 동작을 설계합니다.
- 시뮬레이션과 실제 로봇 테스트를 통해 이동 성능과 안정성을 개선합니다.

## 지원자격
- 로봇 Navigation, Path Planning, Motion Planning 경험이 필요합니다.
- ROS/ROS2 기반 navigation stack 이해와 개발 경험이 있으면 적합합니다.
- C++/Python 기반 알고리즘 구현 능력이 필요합니다.

## 우대사항
- Nav2, SLAM, Localization, Costmap 튜닝 경험
- 휴머노이드 보행 제어와 경로 계획 연동 경험
- 동적 장애물 회피, 사람 밀집 환경 주행 경험
