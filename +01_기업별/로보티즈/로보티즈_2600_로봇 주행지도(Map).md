# 로봇 주행지도(Map) 엔지니어

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 모바일 로봇의 주행 경로 계획과 위치 추정을 위한 지도 데이터를 구축합니다.
- 현장 환경을 분석하여 로봇이 이동 가능한 영역, 제한 구역, 충전 위치 등을 정의합니다.
- 지도 생성, 편집, 검증 도구를 운영하고 주행 품질을 개선합니다.
- 주행 로그를 기반으로 지도 오류와 위치 추정 문제를 분석합니다.

## 지원자격
- 모바일 로봇, SLAM, Navigation 관련 기본 지식이 필요합니다.
- 지도 데이터 처리와 현장 테스트를 수행할 수 있는 문제 해결 능력이 필요합니다.
- Linux, Python, ROS/ROS2 환경에 익숙하면 적합합니다.

## 우대사항
- 실내외 배송로봇 또는 AMR 지도 구축 경험
- LiDAR SLAM, Visual SLAM, Localization 튜닝 경험
- 현장 실증 및 로봇 운영 데이터 분석 경험
