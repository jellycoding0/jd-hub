# 휴머노이드 강화학습 엔지니어

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 휴머노이드 보행, 균형, 조작 동작을 위한 강화학습 정책을 개발합니다.
- observation, action, reward, termination 조건을 설계하고 학습 안정성을 개선합니다.
- 시뮬레이터 기반 대규모 학습과 실제 로봇 적용을 위한 Sim-to-Real 전략을 수립합니다.
- 학습 결과를 제어 시스템과 통합하고 실기체 테스트로 성능을 검증합니다.

## 지원자격
- Reinforcement Learning, 로봇 제어, 물리 시뮬레이션 경험이 필요합니다.
- PyTorch 기반 학습 코드 구현과 실험 분석 역량이 필요합니다.
- 로봇 운동학/동역학 또는 제어 이론에 대한 이해가 있으면 적합합니다.

## 우대사항
- Isaac Gym/Lab, MuJoCo, Legged Gym 등 활용 경험
- 휴머노이드/족형 로봇 보행 정책 개발 경험
- Domain Randomization, Policy Distillation, Sim-to-Real 경험
