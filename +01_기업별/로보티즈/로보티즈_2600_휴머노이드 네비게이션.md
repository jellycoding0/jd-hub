# 휴머노이드 네비게이션 연구원

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 휴머노이드 로봇의 이동 목표 설정, 경로 계획, 장애물 회피 알고리즘을 연구합니다.
- 보행 가능한 지형과 이동 제약을 고려한 휴머노이드 특화 navigation 기능을 개발합니다.
- Perception, Localization, Control 모듈과 navigation 결과를 연동합니다.
- 시뮬레이션 및 실제 환경에서 이동 실패 케이스를 분석하고 개선합니다.

## 지원자격
- 로봇 navigation, path planning, motion planning 관련 연구/개발 경험이 필요합니다.
- ROS/ROS2 기반 시스템 통합과 C++/Python 구현 역량이 필요합니다.
- 확률적 계획, 최적화, 그래프 탐색 알고리즘에 대한 이해가 있으면 적합합니다.

## 우대사항
- 휴머노이드 또는 이동 로봇 navigation 연구 경험
- Nav2, SLAM, Costmap, Behavior Tree 활용 경험
- 동적 환경, 사람-로봇 공존 공간에서의 이동 계획 경험
