# 휴머노이드 시스템 소프트웨어 연구원

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 휴머노이드 로봇의 시스템 아키텍처와 소프트웨어 프레임워크를 연구합니다.
- 제어, 인식, 학습, 통신 모듈이 안정적으로 동작하는 런타임 구조를 설계합니다.
- 로봇 상태 관리, 모듈 간 메시징, 장애 대응, 로그/모니터링 기능을 개선합니다.
- 실험실 연구 코드가 실제 로봇에서 반복 운용될 수 있도록 시스템화합니다.

## 지원자격
- 로봇 시스템 소프트웨어, middleware, embedded Linux 경험이 필요합니다.
- C++/Python, ROS/ROS2 기반 대규모 로봇 소프트웨어 개발 경험이 있으면 적합합니다.
- 시스템 디버깅, 성능 분석, 안정화 역량이 필요합니다.

## 우대사항
- ROS2 middleware, DDS, real-time control loop 경험
- 휴머노이드 또는 다관절 로봇 시스템 통합 경험
- CI/CD, 테스트 자동화, 로봇 SW 배포 경험
