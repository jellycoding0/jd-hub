# 휴머노이드 시스템 소프트웨어 엔지니어

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 휴머노이드 로봇의 ROS2 기반 시스템 소프트웨어를 개발합니다.
- 센서, 액추에이터, 제어기 등 하드웨어 모듈을 소프트웨어와 연동합니다.
- DYNAMIXEL 및 ros2_control 기반 controller, hardware interface를 개발하고 안정화합니다.
- 실기체 환경에서 발생하는 시스템 이슈를 분석하고 성능을 개선합니다.

## 지원자격
- C++ 또는 Python 기반 개발 경험이 필요합니다.
- ROS/ROS2, Linux 환경에서 로봇 소프트웨어를 개발한 경험이 필요합니다.
- 로봇 하드웨어 연동, 디버깅, 로그 분석에 대한 기본 이해가 필요합니다.

## 우대사항
- DYNAMIXEL SDK, ros2_control, hardware interface 개발 경험
- 휴머노이드, 모바일 로봇, 매니퓰레이터 시스템 통합 경험
- 실시간 제어, 센서 드라이버, embedded Linux 경험
