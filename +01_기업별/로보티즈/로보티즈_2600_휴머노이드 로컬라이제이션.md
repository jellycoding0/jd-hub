# 휴머노이드 로컬라이제이션 연구원

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 휴머노이드 로봇의 위치, 자세, 상태를 추정하는 알고리즘을 연구합니다.
- 보행 충격과 센서 노이즈가 있는 상황에서도 안정적인 state estimation을 구현합니다.
- 카메라, IMU, LiDAR, 관절 센서 데이터를 융합하여 위치 추정 정확도를 높입니다.
- Navigation 및 Control 모듈과 추정 결과를 실시간으로 연동합니다.

## 지원자격
- SLAM, Localization, Sensor Fusion, State Estimation 경험이 필요합니다.
- 수학적 모델링, 확률 필터, 최적화 기반 추정에 대한 이해가 필요합니다.
- C++/Python, ROS/ROS2 환경에서 실험을 수행할 수 있어야 합니다.

## 우대사항
- VIO, LiDAR SLAM, factor graph 기반 추정 경험
- 휴머노이드/족형 로봇의 동적 상태 추정 경험
- 실기체 데이터 기반 캘리브레이션 및 디버깅 경험
