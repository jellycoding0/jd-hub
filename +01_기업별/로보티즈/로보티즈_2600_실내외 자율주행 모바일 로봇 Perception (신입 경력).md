# 실내외 자율주행 모바일 로봇 Perception 엔지니어 (신입/경력)

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 실내외 자율주행 로봇의 객체 인식, 장애물 인식, 주행 환경 이해 기능을 개발합니다.
- 카메라, LiDAR, IMU 등 센서 데이터를 융합하여 주행 판단에 필요한 정보를 제공합니다.
- 딥러닝 기반 인식 모델을 학습, 평가, 최적화하고 로봇 시스템에 배포합니다.
- 현장 주행 데이터를 분석하여 오탐, 미탐, 환경 변화 대응 성능을 개선합니다.

## 지원자격
- 컴퓨터비전, 딥러닝, 로봇 Perception 중 하나 이상의 경험이 필요합니다.
- Python/C++ 기반 모델 개발 및 데이터 처리 경험이 필요합니다.
- 신입은 관련 프로젝트 경험, 경력은 실서비스 또는 실기체 적용 경험이 있으면 적합합니다.

## 우대사항
- Object Detection, Segmentation, Tracking, 3D Perception 경험
- ROS/ROS2 기반 센서 파이프라인 개발 경험
- TensorRT, ONNX 등 모델 최적화 및 온디바이스 배포 경험
