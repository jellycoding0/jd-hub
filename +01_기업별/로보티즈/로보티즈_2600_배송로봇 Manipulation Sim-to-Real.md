# 배송로봇 Manipulation Sim-to-Real 연구원

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 배송로봇 매니퓰레이션 작업을 시뮬레이션에서 학습하고 실제 로봇에 적용합니다.
- 물체 파지, 문/버튼/엘리베이터 조작 등 실제 환경 태스크를 모델링합니다.
- 도메인 랜덤화, 센서 노이즈, 물리 파라미터 튜닝을 통해 Sim-to-Real 성능을 개선합니다.
- 실험 데이터를 분석하여 정책, 제어기, 시뮬레이션 모델을 반복 개선합니다.

## 지원자격
- 로봇 매니퓰레이션, 강화학습, 모방학습 중 하나 이상의 경험이 필요합니다.
- Isaac Sim/Lab, MuJoCo, PyBullet 등 물리 시뮬레이터 활용 경험이 있으면 적합합니다.
- Python, C++, ROS/ROS2 기반 실험 구현 역량이 필요합니다.

## 우대사항
- 실제 로봇 팔 또는 모바일 매니퓰레이터 실험 경험
- 정책 학습, reward 설계, domain randomization 경험
- 비전/힘 센서 기반 조작 태스크 개발 경험
