# AI 로봇 데이터 Curation 엔지니어

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 로봇 학습에 사용할 시연, 주행, 조작 데이터를 수집하고 품질을 관리합니다.
- 실패 사례, 이상치, 중복 데이터를 분류하고 학습에 적합한 데이터셋으로 정제합니다.
- 데이터 라벨링 기준, 버전 관리, 품질 지표를 설계하여 학습 파이프라인과 연결합니다.
- 연구원 및 엔지니어와 협업하여 모델 성능 개선에 필요한 데이터 요구사항을 정의합니다.

## 지원자격
- Python 기반 데이터 처리 및 분석 경험이 필요합니다.
- 이미지, 센서, 로봇 로그 등 비정형 데이터를 다뤄본 경험이 있으면 적합합니다.
- ML 데이터셋 구조, 라벨링, 검수 프로세스에 대한 이해가 필요합니다.

## 우대사항
- 로봇, 자율주행, 비전 AI 데이터 구축 경험
- MLOps, DataOps, 데이터 버전 관리 도구 활용 경험
- ROS/ROS2 bag, 카메라, LiDAR, IMU 데이터 처리 경험
