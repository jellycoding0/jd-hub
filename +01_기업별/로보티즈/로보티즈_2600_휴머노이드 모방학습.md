# 휴머노이드 모방학습 엔지니어

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 사람 시연 데이터나 원격조작 데이터를 활용해 휴머노이드 행동 정책을 학습합니다.
- 데이터 수집, 정제, 행동 라벨링, policy learning 파이프라인을 구축합니다.
- 보행, 조작, 양팔 작업 등 휴머노이드 태스크에 적합한 imitation learning 모델을 개발합니다.
- 실제 로봇 적용 결과를 분석하여 데이터와 모델을 반복 개선합니다.

## 지원자격
- Imitation Learning, Behavior Cloning, 로봇 학습 경험이 필요합니다.
- PyTorch 기반 모델 학습과 데이터 처리 경험이 필요합니다.
- 로봇 제어, 센서 데이터, 시뮬레이터 중 하나 이상의 이해가 있으면 적합합니다.

## 우대사항
- Teleoperation, motion retargeting, human demonstration 데이터 활용 경험
- Diffusion Policy, ACT, VLA 등 로봇 정책 모델 경험
- 휴머노이드 또는 매니퓰레이터 실기체 적용 경험
