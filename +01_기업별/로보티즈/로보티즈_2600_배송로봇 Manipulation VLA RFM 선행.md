# 배송로봇 Manipulation VLA/RFM 선행연구원

원문 링크: https://robotis.notion.site/robotis-recruiting

## 수행업무
- 배송로봇의 조작 작업에 VLA, RFM 등 로봇 파운데이션 모델을 적용합니다.
- 언어 명령, 시각 정보, 로봇 상태를 행동으로 연결하는 정책 모델을 연구합니다.
- 데이터 수집, 사전학습, 파인튜닝, 평가 체계를 설계합니다.
- 기존 제어/인식 시스템과 상위 AI 정책을 통합하여 실제 태스크 성공률을 높입니다.

## 지원자격
- 딥러닝, 로봇학습, 멀티모달 모델 중 하나 이상의 연구/개발 경험이 필요합니다.
- PyTorch 기반 모델 학습과 실험 관리 경험이 필요합니다.
- 로봇 조작 문제와 데이터 기반 정책 학습에 대한 이해가 있으면 적합합니다.

## 우대사항
- VLA, RFM, imitation learning, reinforcement learning 경험
- 로봇 데이터셋 구축 및 policy evaluation 경험
- 실제 로봇 또는 시뮬레이터 기반 manipulation 연구 경험
