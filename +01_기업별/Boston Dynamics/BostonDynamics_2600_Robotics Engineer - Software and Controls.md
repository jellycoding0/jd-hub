# Robotics Engineer - Software and Controls

## 공고 기준
- 회사: Boston Dynamics
- 출처: https://bostondynamics.wd1.myworkdayjobs.com/en-US/Boston_Dynamics/job/Robotics-Engineer--Software-and-Controls_R2145

## 직무 개요
로봇의 software와 controls를 함께 다루는 엔지니어 직무
모터 제어, 로봇 센싱, safety system, behavior control을 연결해 실제 로봇 기능을 구현하는 역할

## 주요 업무
- Robotics software 및 controls 개발
- Motor control 관련 기능 구현
- Robot sensing 데이터 처리
- Safety system과 behavior control 통합
- 실제 로봇 테스트 및 성능 튜닝

## 요구 역량
- C++ 기반 개발 경험
- 로봇 제어와 센서 처리 이해
- Motor control 및 embedded/real-time system 이해
- Safety-critical system 개발 감각
- 실기체 debugging과 integration 경험
