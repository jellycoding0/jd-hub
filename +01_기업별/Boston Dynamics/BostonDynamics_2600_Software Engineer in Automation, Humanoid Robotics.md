# Software Engineer in Automation, Humanoid Robotics

## 공고 기준
- 회사: Boston Dynamics
- 출처: https://bostondynamics.wd1.myworkdayjobs.com/en-US/Boston_Dynamics/job/Software-Engineer-in-Automation--Humanoid-Robotics_R2794

## 직무 개요
Atlas 휴머노이드 로봇 개발을 위한 HIL(Hardware-in-the-Loop) 및 자동화 테스트를 개발하는 직무
로봇 기능을 빠르고 안정적으로 검증할 수 있는 테스트 인프라를 만드는 역할

## 주요 업무
- Humanoid robotics automation software 개발
- HIL 테스트 환경 구축
- Regression test 및 validation pipeline 개발
- 로봇 하드웨어/소프트웨어 통합 테스트 자동화
- 테스트 결과 분석 및 품질 개선

## 요구 역량
- Python/C++ 기반 automation 개발 경험
- Test infrastructure, CI, hardware integration 이해
- 로봇 또는 임베디드 시스템 검증 경험
- 실험 장비와 로봇 하드웨어를 다루는 능력
- 반복 테스트를 안정적으로 자동화하는 역량
