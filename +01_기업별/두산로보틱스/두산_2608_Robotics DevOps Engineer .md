# Robotics DevOps Engineer

## 합류할 팀을 ​소개해요!
두산로보틱스의 AI/SW 본부에 새롭게 신설되는 팀에서 다양한 로보틱스 및 소프트웨어 문제를 분석/해결할 수 있는 솔루션 만들어요. 로보틱스 소프트웨어 플랫폼을 직접 설계, 개발, 운영하는 업무를 수행할 예정입니다. 소프트웨어의 End to End를 수행한다고 봐주시면 좋을 것 같아요! 내부 생산성을 높이고 시스템 효율을 높이며 자체 솔루션도 만들고, AI를 활용해 Agentic 솔루션과 파이프 라인을 만들어가며 자동화를 이끌! 멋진 동료를 기다립니다!!🤗

## 이런 미션을 주도해요! (Key Responsibilities)
로보틱스 플랫폼의 인프라 환경(EKS 기반)을 설계, 운영 및 고도화 해요.
서비스별 배포 파이프라인(CI/CD)을 자동화하고, 효율적인 개발 프로세스를 구축해요.
장애 모니터링 및 로그 수집 체계를 고도화하여 선제적으로 문제를 탐지하고 대응해요.
Kubernetes, Cloud Native 환경에서 안정적이고 확장 가능한 운영 환경을 구현해요.
내부 개발자들이 쉽게 배포·운영할 수 있도록 개발자 중심의 DevOps 문화를 만들어요.

## 본격적인 시작 전, 먼저 확인해 주세요!
학사 이상 학위 소지자 
남자의 경우 병역 이행을 완료하였거나 면제된 분
해외여행 또는 해외 근무에 결격사유가 없는 분
국가공무원법상 채용결격사유에 해당하지 않는 분
 

## 아래와 같은 역량을 증명해 오신 분을 찾아요! (Requirements)
Kubernetes, Docker 기반 클라우드 인프라 운영 경험이 7년 이상인 분
Jenkins, GitHub Actions, ArgoCD 등 CI/CD 환경 구축 및 개선 경험이 있는 분
Infrastructure as Code (Terraform, Helm 등) 활용 능력을 갖추신 분
로깅, 모니터링 (Grafana, Prometheus, Loki 등) 환경 구성 경험이 있는 분
시스템 장애의 근본 원인 분석 및 구조적 개선 경험이 있는 분

## 사용하는 기술을 알려드릴게요!
AWS EKS 기반 Kubernetes 운영 : 서비스 pod 관리, 오토스케일링, 네트워크 구조 설계 및 개선
IaC (Terraform, Helm) : 인프라 환경을 코드로 관리하고, 배포 재현성과 안정성 확보
CI/CD (GitHub Actions, ArgoCD, Jenkins) : 서비스 빌드·배포 자동화 및 지속적 개선
Observability (Prometheus, Grafana, Loki, ELK Stack) : 모니터링, 로깅, 알람 시스템 구축
 

## 이런 경험이 있으시면 더욱 강력한 시너지를 낼 수 있어요! (Preferred Qualifications)
로보틱스나 IoT 환경에서의 Edge-Cloud 통합 운영 경험이 있는 분
