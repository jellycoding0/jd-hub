# 관절 로봇 제어

## 직무상세
- 상/하반신을 포함한 착용로봇 플랫폼 및 매니퓰레이터 제어 알고리즘 개발

- 생체신호 및 각종 모션 관련 센서 / 엑츄에이터 등을 이용한 예측 제어 및 모델 기반 제어

- 로봇 제어를 위한 임베디드 환경에서 제어 알고리즘 프로그래밍


[제어 알고리즘]

- 로봇 플랫폼의 동역학 기반 제어 및 시뮬레이션

- 직/간접 토크 기반 제어 및 알고리즘 개발

- 학습 기반 경로 계획 및 모션 제어 알고리즘 개발

- 착용자 모션/보행 인지 및 예측 알고리즘 개발


[제어 프로그래밍]

- 임베디드 환경에서 실시간성을 고려한 로봇 제어 알고리즘 프로그래밍

- Real-Time OS 기반 로봇 제어 알고리즘 구현

- 고속 연산을 위한 알고리즘 최적화


[시스템 프로그래밍]

- 시스템 운영을 위한 FSM(Finite State Machine) 설계

- 시스템 주변 장치 제어 및 유/무선 통신 구현

- CANopen, EtherCAT 통신의 구현 및 이해
