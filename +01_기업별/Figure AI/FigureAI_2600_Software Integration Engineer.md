## 직무 개요
휴머노이드 로봇의 여러 소프트웨어 모듈을 통합하고, 실제 로봇에서 안정적으로 동작하도록 검증하는 직무
AI, controls, firmware, platform software 사이의 interface를 연결하는 역할

## 주요 업무
- 로봇 SW module integration
- CI/test pipeline 기반 통합 검증
- 로봇 로그 분석 및 regression 대응
- Hardware/software interface 문제 해결
- 배포 전 기능 검증과 품질 관리

## 요구 역량
- C++/Python, Linux 개발 경험
- 대규모 software integration 경험
- 로봇 또는 임베디드 시스템 debugging 경험
- CI/CD, test automation, logging 이해
- 여러 팀 사이의 interface를 정리하는 커뮤니케이션 능력
