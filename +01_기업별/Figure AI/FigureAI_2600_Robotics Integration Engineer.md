# Robotics Integration Engineer

## 공고 기준
- 회사: Figure AI
- 근무지: San Jose, CA
- 출처: https://job-boards.greenhouse.io/figureai/jobs/4387319006

## 직무 개요
휴머노이드 로봇의 하드웨어, 소프트웨어, 제어, AI 모듈을 실제 시스템으로 통합하는 직무
개별 기능이 로봇 전체에서 안정적으로 동작하도록 bring-up, test, debugging을 수행하는 역할

## 주요 업무
- 로봇 시스템 통합 및 bring-up
- 센서, 액추에이터, 제어기, SW stack 연동
- 실기체 테스트와 로그 분석
- 시스템 수준 failure 분석 및 개선
- Cross-functional 팀과 통합 일정 관리

## 요구 역량
- Robotics system integration 경험
- C++/Python, Linux 기반 개발 경험
- 센서/액추에이터/통신 인터페이스 이해
- 실험 장비와 로그를 활용한 디버깅 역량
- 빠른 하드웨어 개발 환경에서 문제를 좁히는 능력
