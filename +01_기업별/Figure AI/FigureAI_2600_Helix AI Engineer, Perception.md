# Helix AI Engineer, Perception

## 공고 기준
- 회사: Figure AI
- 근무지: San Jose, CA
- 출처: https://job-boards.greenhouse.io/figureai/jobs/4007375006

## 직무 개요
휴머노이드 로봇이 주변 환경과 물체를 이해하도록 perception 모델과 시스템을 개발하는 직무
비전 모델을 로봇 조작, 이동, 행동 의사결정과 연결하는 역할

## 주요 업무
- Robot perception 모델 개발
- Object detection, segmentation, pose estimation, scene understanding
- 로봇 센서 데이터 처리 및 모델 평가
- Manipulation / planning stack과 perception 결과 통합
- 실제 로봇 환경에서 perception failure 분석

## 요구 역량
- Computer vision 및 deep learning 경험
- Python, PyTorch 기반 모델 개발
- RGB-D, multi-camera, sensor calibration 이해
- 로봇 task와 연결된 perception pipeline 경험
- 실시간 inference 및 모델 최적화 경험
