# Helix AI Engineer, Robot Learning

## 공고 기준
- 회사: Figure AI
- 게시일: 2026-01-30
- 근무지: San Jose, CA
- 출처: https://job-boards.greenhouse.io/figureai/jobs/4649851006

## 직무 개요
Figure의 Helix AI 팀에서 휴머노이드 로봇의 robot learning 기능을 개발하는 직무
로봇이 실제 환경에서 조작과 행동을 학습하고 일반화하도록 모델, 데이터, 평가 파이프라인을 다루는 역할

## 주요 업무
- Robot learning 모델 개발
- 로봇 데이터 기반 policy 학습
- Manipulation 및 embodied AI task 성능 개선
- 실제 로봇 배포를 고려한 모델 평가
- AI, controls, software, hardware 팀과 협업

## 요구 역량
- Python, PyTorch 기반 ML 개발
- Robotics, manipulation, imitation learning 또는 reinforcement learning 경험
- 대규모 데이터 처리 및 실험 관리 역량
- 실제 로봇 또는 시뮬레이터 기반 학습 경험
- 연구 결과를 제품 기능으로 연결하는 엔지니어링 역량
